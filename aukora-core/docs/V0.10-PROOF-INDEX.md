# v0.10: what is proved, and where

`v0.10/PROVED.md` is a carried page from an earlier version (see [ERRATA](../ERRATA.md)). This is v0.10's own index.
Every statement below is about the Lean MODEL of the core, checked by the Lean 4.19.0 kernel. None of them is a
guarantee about the compiled files, the compiler, the host around the core, the signature algorithms or the
machine it runs on; for how the model was compared with the compiled files, see [NEXT-LINE](../NEXT-LINE.md).

## The law set
- `v0.10/Proofs/PublicLawful.lean`, `full_lawful` (line 627): the root proposition `Lawful` holds of the v0.10
  machine. It has 46 named fields: v0.8's 44, restated where needed, plus `refused_refuses` (a refused form is
  refused and the state is unchanged) and `essentials_open` (halt, clear, the newer key change, seal and
  continuation can never be put on the refused list). The build checks that the in-file proof checker refuses each of 46 packages that drop one named law (`v0.10/tests/GateFinalChecks.lean`, run by `v0.10/tools/build.py`).
- Same file, `refusal_is_lawful` (line 678): the whole law set holds of a machine that refuses a refused approval.

## The bound record
- `v0.10/Proofs/BoundRefuses.lean`, `bound_refuses_legacy` (lines 37 to 54): in every state reachable from a bound
  start, a plain approval and an old key change are refused, whatever record or head their bytes name.
- Same file, `bound_recovery`: in every state reachable from a bound start, a valid clear and a valid newer key change are admitted (no lockout
  by the refused list).

## Added in hardening round 1 (outside the frozen folder, same kernel)
- `hardening/BoundEffects.lean`: `bound_grant_source` (in a bound record, a new grant appears only from a timed
  approval signed by both owner keys) and `bound_owner_change` (the owner's keys change only by a key change
  addressed to that record).
- `hardening/Obligations.lean`: refusal is a no-op, deny overrides, the order of the list does not matter, the list
  never loses a member, and any history equals the inner machine's history over the unrefused inputs.

## Not proved
That the compiled files behave like the model (tested, not proved: `drt/`), that no other form reaches an
effect not named above, anything about two records started with the same descriptor, and anything about the host.
The refused list of a record is fixed at its start; no frame can change it yet. Read `v0.10/NOT-PROVED.md` together
with [ERRATA](../ERRATA.md).
