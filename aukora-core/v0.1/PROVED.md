# The public contract

`Aukora.Release.Lawful` has 23 fields. `newest_lawful` instantiates them with the public byte dispatcher, genesis, staging, stamp and outcome operations. `lawful_withGenesis` transports all 23 fields through any function on genesis input bytes. The fixed-key fixture uses that theorem. Both declarations and all field statements are in [Laws.lean](Laws.lean). The machine and the finite command interpreter are in [ReleaseInterface.lean](ReleaseInterface.lean).

Below, unqualified theorem names belong to `Aukora.Release`. “From genesis” assumes that the candidate's initialization accepted the supplied key bytes. “Accepted” means the candidate's step returned the indicated successor. Every other state in a law may be supplied directly. Proofs quantify over the checker context. The Wasm adapter initializes the checker from the environment embedded in the module. The public ABI gives the host no argument for supplying a different environment. Signature acceptance means the concrete Lean Ed25519 and ML-DSA-65 verification functions returned true on the messages identified by the theorem.

### Interpreting prior interface laws

L6 concerns the ordinary advisory score. The danger score is an input to the admission policy and follows D1–D5. L10 retains the former ever-confirmed predicate on the public ledger model. The Wasm's current outcome query also represents failure, correction and absence. Applying the old two-result biconditional directly to that query would be false after a confirmed report is corrected to failed. The historical predicate has no separate Wasm export. L8 uses the new carried package and constructed goal. H1 and H2 use the current hybrid message domains in place of the old Ed-only message domains. The ten historical guarantees have their scoped counterparts above.

The positive availability clauses quantify over the frozen reference policy in the same state. They prevent a candidate from passing cancellation, timed-issue, assessment, threshold, reporting and stamp obligations solely by refusing every input in that class. Hash collisions, cryptographic correctness, external beacon or receipt verification, and correspondence of the staged executable to the carried model have no proof here. ### Replay-only profile

The kernel also accepted `Aukora.Release.LiteProof.lawful : Lawful lite` for the same 23 fields. The lite dispatcher refuses every installation package. L8 constrains a change of installed digest, so a session with no such change satisfies it. The positive guarantees for eligible assessment, threshold, timed issue, revocation, reporting and stamp inputs still apply. On arbitrary traces, lite produces the full machine's state after removing all tag-27 submissions. Replaying an original history that accepted an installation requires the full core.
