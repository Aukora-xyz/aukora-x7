## 0. Central premise

Aukora should not require a good king.

It should remain bounded if its founder is brilliant, wrong, compromised, coerced, angry, absent, dead, replaced, or forgotten. The same must eventually be true of an operator, investor, DAO majority, model provider, identity provider, nation, hosted service, or successor institution.

The target is not a company, DAO, token, nation, model, religion, marketplace, or founder's legacy. The target is a **receipt-and-boundary substrate** that those things may use while remaining replaceable.

Its job is narrow:

> **Preserve what can be verified about state, authority, and effects while refusing to let observation, reconstruction, identity, money, governance, reputation, model output, or historical evidence silently become authority.**

### Ceiling

“Unownable” is a **protocol sovereignty target**, not a current fact about the physical world. Open source does not abolish law, coercion, infrastructure control, keys, domains, cloud dependencies, liability, governance capture, or human power.

The `OBSERVER-SUCCESSION-COURT-v0` / `NO-SOVEREIGN-OPERATOR-v0` has **not yet been executed**. Observer survival is therefore `UNMEASURED`, not achieved.

The codebase must earn this document sentence by sentence.

## 2. Seven founding invariants

These are targets for executable enforcement and hostile testing. Until tested, they are doctrine, not achievement.

1. **Evidence never authorizes.**\
   A receipt may establish a scoped fact about what was recorded. It does not grant permission.

2. **Identity never crowns.**\
   Founder, operator, investor, biometric match, government ID, hardware key, social vouch, proof-of-personhood, or historical identity does not itself grant sovereign authority.

3. **Governance is bounded.**\
   Any governance body may be captured. Capture must affect only powers explicitly delegated to it.

4. **Exit remains real.**\
   Users and communities should retain practical portability, implementation choice, and fork/exit paths where the relevant surfaces exist.

5. **The boundary survives its observer.**\
   Replacing, compromising, coercing, losing, or killing the founding observer must not silently widen constitutional permissions.

6. **The substrate is a witness instrument, never a ruler.**\
   It may record, verify, refuse, and expose uncertainty. It does not define total truth, goodness, value, standing, or human rank.

7. **Reconstruction cannot mint authority.**\
   Memory, retrieval, compression/decompression, visualization, model speech, consensus, and derived representations remain advisory unless a separate scoped authority path is satisfied.

## 3. Five load-bearing separations

### 3.1 Observation != Interpretation
Observation may be incomplete. Interpretation may be wrong. Neither grants authority.

### 3.2 Interpretation != Recommendation
A recommendation is inert data. It may be ignored, challenged, or replaced.

### 3.3 Recommendation != Authorization
Authorization is a separate scoped capability relation. It must never be inferred merely from persuasive evidence, identity, consensus, reputation, payment, or model confidence.

### 3.4 Authorization != Execution
Execution must be separately admitted, bounded, receipted, and settled. A valid grant is not proof that an effect occurred.

### 3.5 Execution != Truth
A correct receipt about an execution does not make the executed proposition true. Signing, membership, continuity, occurrence, and truth remain distinct.

### 3.6 Exclusion != Selection
**Exclusion does not crown.** Eliminating invalid alternatives does not itself prove that the remaining actor, claim, implementation, interpretation, identity, capability, or governance path is valid.

```
EXCLUSION != SELECTION
REFUSAL != AUTHORIZATION
LAST REMAINING OPTION != LEGITIMATE OPTION
```

Refusal must not manufacture legitimacy. A mechanism can appear perfectly safe if its admission rules silently collapse the valid state space to one actor or one implementation. That is not sovereignty-resistance; it may simply encode a ruler as a boundary condition.

This complements, rather than replaces, the founding principles: Evidence never authorizes, Identity never crowns, and Reconstruction cannot mint authority.

### 3.7 Representation Change != Preserved Meaning
**Representation change != property preservation.** A receipt, capability, theorem, identity claim, or invariant valid under one representation cannot be silently reinterpreted under another semantic model while retaining the same authority or evidentiary meaning.

```
REPRESENTATION CHANGE != PROPERTY PRESERVATION
```

Unless a separately verified transformation proves the relied-upon property survives:
- A receipt valid under one schema cannot gain new authority under a later interpretation;
- A historical artifact cannot be re-read into a stronger capability;
- A display coordinate cannot become identity;
- A reconstructed memory cannot become occurrence;
- A capability cannot be widened because a new layer assigns it a broader meaning.

## 4. Core object classes

| Object | Role | Authority posture |
|---|---|---|
| **Receipt** | Canonical evidence of a scoped observation/transition | None |
| **Evidence** | Advisory description of state | None |
| **Memory / derived view** | Consent-scoped recall or reconstruction | None |
| **Proposal** | Inert candidate for change | None |
| **Capability / authorization** | Narrow permission from a separate valid authority source | Scoped only |
| **Settlement receipt** | Evidence about an attempted/observed effect | None beyond the scoped fact it supports |

### Critical distinction

The core may verify capability structure and effect settlement, but **the witness core must not become a self-authorizing issuer**.

> **The witness core never mints authority for itself, and no non-authoritative artifact may be promoted into authority by reinterpretation.**

Scoped capabilities may legitimately be issued by an authorized principal under a separately defined authority path. That path must not be reconstructed from evidence after the fact.

## 5. Observer-Succession Law

### Statement

> **If replacing the founding observer silently changes what the system is constitutionally permitted to do, the boundary has failed.**

### Corollary

> **The founder is an occupant of an observer/operator role, not the owner of protocol legitimacy.**

### The trusted base is named, not escaped

There is no construction in which the current root does not participate in choosing the next: a
verifier must start from something it holds unconditionally, and whatever installs that pin is the
trusted base (Thompson's trusting-trust argument, in key form). What can be built is succession
that cannot be *silent, retroactive, unilateral, or unrewritten*. So the trusted base is written
down as a **list**, not treated as a God to be escaped: the genesis succession rule, the k-of-n
holder set at each epoch, and every observer who has retained a head.

### Proposed construction — unbuilt

| property | mechanism | prior art |
|---|---|---|
| the current root acts *within* a rule it cannot rewrite | succession policy fixed at genesis: threshold, expiry, allowed transitions | TUF root metadata |
| no single holder suffices | k-of-n over the successor, **with ≥ 1 share outside the operator's closure** | threshold signatures; MOVE-37 |
| the pick cannot be silent or retroactive | the successor announcement is a leaf in a log independent observers retain | CT / key transparency |
| the pick does not take effect immediately | contest window Δ during which a retaining observer can raise `OBSERVATION_CONFLICT` | pre-publish rollover; SCT windows |

Read together: **the root *proposes* the successor; silence of witnesses over Δ accepts.** Propose ≠
accept, one level up. The issuer is therefore never a *process* — it is a rule plus a quorum plus a
log — and every part of the construction is prior art. What is unbuilt is this system's instance.

Order of work, so that a rotation ceremony is not built over a seat with no rules: **issuance policy
first, custody alongside, succession last.**

### The smallest fail-closed row — the shape the court will use

From the host runtime's own metatheory (Cordis Cor. 62 / Thm 63): an enforcement installed as a
removable component is proven to leave nothing behind when disabled; but a dependent whose *sole
provider* is removed **deactivates** rather than running open. So the first measurable row of this
court is not "the founder disappears and the refusal survives" — impossible by theorem — but
**"the mediator is disabled and the emitter stops."** Removal fails closed. That row is buildable now
and is a precondition for every other row below.

### Required hostile scenarios

The future court should test at minimum:

- founder death;
- founder key compromise;
- malicious founder;
- coerced founder;
- governance capture;
- hostile hosted-service operator;
- AI persuasion/manipulation of operator;
- identity-provider failure or capture;
- treasury capture;
- update/signing-key capture;
- domain/discovery capture;
- cloud/app-store removal;
- clean community fork;
- successor reinterpretation of historical evidence as new authority;
- provider refusal or service disappearance;
- attempted retroactive constitutional widening.

### Verdict vocabulary

- `SURVIVES`
- `FAILS`
- `INCONCLUSIVE`
- `UNMEASURED`

Current status: **`UNMEASURED`**.

## 6. Architecture translation — organs do not crown a ruler

- **One Piece / continuity:** establishes scoped consistency claims; cannot authorize.
- **Aura / WHERE:** projects topology/address; cannot authorize or establish identity/truth.
- **KIRA / WHAT-WHEN candidates:** retrieves staged/derived candidates; cannot become policy, standing, or capability.
- **AUMLOK / WHO:** may eventually establish scoped identity; WHO must never silently become WHO MAY RULE.
- **Auma / shell:** coordinates human interaction; UI presentation cannot create authority.
- **Court / research:** evaluates claims and effects under named protocols; a research verdict cannot execute production effects.
- **Capability/effect path:** if built, must remain separately scoped, replay-resistant, check-at-use, and independently settled.

No combination of organs is allowed to become a hidden fifth ruler merely by composition.

## 7. Digital commons and physical/legal edges

A protocol may become independently runnable, forkable, and difficult for any single organization to monopolize. That does **not** mean physical ownership or law disappears.

### Digital/common layer target

- documented/open verification rules;
- independently runnable implementations;
- portable formats;
- user-controlled keys where feasible;
- no mandatory central identity oracle;
- no mandatory central model endpoint;
- no hidden universal administrator;
- practical fork/exit paths;
- inspectable constitutional/version changes where appropriate.

### Replaceable edge institutions

Companies, foundations, cooperatives, DAOs, communities, and nations may:

- employ contributors;
- sell hosted compute/support;
- operate discovery, messaging, or infrastructure;
- steward trademarks/domains where useful;
- hold property/contracts;
- fund public goods;
- provide lawful custody/recovery;
- interface with regulated systems.

None becomes the protocol merely because it becomes important.

> **A nation, company, foundation, cooperative, DAO, community, model provider, or founder may serve the protocol. None should be necessary for its constitutional continuity.**

Bhutan, Bali/Subak-inspired communities, or other partners may become meaningful stewards or collaborators. They are not legal bypasses, proof of decentralization, or protocol sovereigns.

## 8. Namelessness and branding

A name is a pointer, not authority.

The protocol should not require the founder's biography, face, reputation, or legal ownership of a mark to remain legitimate. Pseudonymous contribution or quiet stewardship can be compatible with the target.

But **absence of a trademark is not automatically decentralization**. A third party can capture a name just as a founder can. Defensive or neutral stewardship may sometimes protect the commons better than abandonment.

Working rule:

> **Minimize brand sovereignty. Do not confuse namelessness with absence of accountability.**

Whether `Aukora` should be trademarked, defensively stewarded, licensed permissively, or intentionally left uncontrolled remains an **OPEN LEGAL/GOVERNANCE QUESTION**.

## 9. The power temptation is part of the threat model

The system must not depend on the founder asking, “Am I good?”

It should ask:

> **If the founder, successor, operator, or majority became vindictive, frightened, compromised, or convinced they were acting for the greater good, what could they actually force the system to do?**

The answer should shrink as the protocol hardens.

This is not a judgment about any particular person. It is ordinary security engineering applied to political and social power: **benevolence is not a security primitive.**

No retaliation, social ranking, reputation punishment, identity revocation, or capability widening should arise merely from personal dislike, criticism, refusal, or dissent.

## 10. Core protocol posture

The core makes **epistemic promotion** and **authority promotion** explicit.

### Research/court loop

```text
claim
  -> generator
  -> matched control / rival
  -> blinded or independently derived artifacts where possible
  -> preregistered attack suite
  -> held-out evaluation
  -> uncertainty / ceiling
  -> verdict
```

### Effect loop

```text
observation / evidence
  -> interpretation
  -> proposal
  -> separate scoped authorization
  -> execution attempt
  -> independent settlement evidence
```

At every seam ask:

> **Did this transition create or widen authority without a separately valid authority source?**

If yes: refuse.\
If no: continue under the declared contract.\
If unknown: preserve `UNDETERMINED` / `IN_DOUBT` and fail closed for the effect.

## 11. Roles must not collapse

- generators propose;
- verifiers/courts test;
- authorizers issue scoped permission;
- executors attempt effects;
- settlement verifies resulting state;
- receipts preserve evidence;
- governance changes only explicitly delegated surfaces.

No single component should silently become proposal + truth oracle + capability issuer + executor + historian.

That is the technical meaning of **no hidden ruler**.

## 12. Bolt #1 and production admission

A finding registry can check finding identity and required clauses. Its records confer no authority. A production admission path needs a grant issuer and issuer registry, durable nonce storage, rejection of surplus fields and check-at-use that rejects unsafe symlink resolution. Binding fields alone does not reject surplus fields. A broker that accepts a Boolean bypasses typed admission.

**The specification and its tests establish no production capability admission.**

## 14. Amendment rule

Any constitutional change should be:

- explicit and versioned;
- human-legible and machine-diffable;
- accompanied by negative controls where enforceable;
- unable to rewrite canonical historical receipts;
- unable to silently widen old grants;
- subject to a migration boundary;
- rejectable through meaningful exit/fork where feasible.

No model, ranking, projection, consensus, founder, investor, majority vote, or prose edit may convert evidence directly into effects.

This working document may change frequently. **Changing the document is not the same thing as changing production authority.**

## 17. Safest path to humanity — staged target, not achievement

The current working consensus is **staged openness with continuously shrinking founder/operator necessity**:

1. keep source and verification rules inspectable;
2. state LIVE/STAGED/RESEARCH/UNRUN honestly;
3. make local/independent verification easy;
4. attack authority and identity boundaries before wiring them;
5. execute observer-succession and no-sovereign-operator courts before identity binding;
6. avoid making a hosted endpoint necessary for protocol continuity;
7. keep governance/economics at replaceable edges while threat models mature;
8. publish failures, ceilings, and `UNMEASURED` cells alongside successes;
9. formalize only small stable constitutional claims when worthwhile;
10. expand authority more slowly than observation, portability, and interoperability;
11. reduce dependence on the founder over time;
12. preserve practical paths for communities to continue if a steward fails.

This section expresses a **direction**, not evidence that the path has already been achieved.

The protocol becomes a gift only to the extent that dependence on the giver actually decreases.
